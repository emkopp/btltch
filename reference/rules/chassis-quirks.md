# Chassis → Design Quirks Table

Per-chassis Design Quirks from the **BattleMech Manual** quirk table (as compiled in the *MegaMek Quirks Reference*). Companion to [design-quirks.md](design-quirks.md), which explains what each quirk does.

**Reading the quirks:** within a chassis, a **semicolon `;`** separates *positive* quirks (before) from *negative* quirks (after); commas separate individual quirks. A parenthetical like `(1)` is the quirk level and `(LA/RA)` etc. is the location or affected weapon. Alternate (Clan) names are shown in parentheses after the chassis name.

> Source: *BattleMech Manual* Design Quirk Table, via the MegaMek Quirks Reference spreadsheet. Design Quirks are an optional rule. Total chassis listed: 468.
