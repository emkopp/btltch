# Campaign Navigator

This folder contains the original map interface for the BattleTech Mercenary
Manager. It displays every known system, highlights destinations reachable within
three jumps, records visited systems, and executes travel through the campaign
manager API.

The user interface and interaction code are specific to this project. System names,
coordinates, affiliations, and jump-neighbor source data in `data/systems.json`
were imported from the earlier local Inner Sphere dataset, whose metadata credited
Sarna.net for planet names and coordinates. BattleTech names and setting elements
remain the property of their respective rights holders.
